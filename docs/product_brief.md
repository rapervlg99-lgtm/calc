# Product brief — калькулятор огнезащиты (ОЗМ)

## Зачем

Онлайн-калькулятор ПТМ для подбора огнезащитных решений ТехноНИКОЛЬ на стальных (и бетонных) конструкциях: толщина/расход материалов, ведомость, выгрузка отчётов.

## Аудитория

- Специалисты ПТМ / проектировщики
- Менеджеры ТН (оценка материалов на объект)

## Делает

- Ввод объекта, групп и элементов (профиль, R, стороны нагрева, длина, покрытие, метод)
- Расчёт δпр, δ, объёмов/масс (ОЗМ, ОЗБ, TAIKOR + сопутствующие)
- Сообщения о недостижимых режимах / АКЗ
- Экспорт Excel / PDF / Word
- Опциональные цены в копейках (overrides) → суммы в Excel

## Не делает (границы)

- Не автозагрузка TN ZIP-прайса в v1 (цены пользовательские)
- Не замена сертификации / экспертизы — ориентировочный расчёт по таблицам ТН

## Смежный контур (в том же репо)

OCR / ОГЗ (`/recognize`) — распознавание таблиц ИД и предзаполнение калькулятора; опционально включается (`OCR_ENABLED`). Визуальный редизайн: см. `docs/tz_ui_redesign.md`.

## Нормативная база (ориентиры)

- ГОСТ Р 53295 и инструкции ТН по огнезащите
- Таблицы t500 (ОЗМ), x500 (TAIKOR) из legacy DC.xml

## Стек целевой

Go API + Vue SPA + Postgres dicts — как калькулятор отмостки.
