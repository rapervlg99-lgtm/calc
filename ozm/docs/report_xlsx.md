# Отчёт «Спецификация» в Excel

Выгрузка по кнопке **Excel** после расчёта (`POST /api/v1/export/xlsx` с `calcId`)
или из нижней панели. Файл собирает `backend/internal/export/xlsx_report.go`
(библиотека excelize), шапка — картинка `assets/report_header.png` (QR-код и
логотип «ТЕХНОНИКОЛЬ · Проектный сервис» одной картинкой, встроена в бинарник).

## Что в файле

Лист на систему, каждая строка — конструкция:

| Лист | Когда появляется | Материалы |
|---|---|---|
| `ТЕХНО ОЗМ+ОЗБ` | есть элементы с покрытием «ТЕХНО ОЗМ» или включена ОЗБ | ТЕХНО ОЗМ, ТЕХНО ОЗБ, клей Ceresit CT 190, штукатурка Ceresit, анкер |
| `Taikor FP Epoxy` / `Taikor FP Graphite` | элементы с покрытием TAIKOR (имя листа — по покрытию) | грунт TAIKOR Primer 150, состав TAIKOR FP, TAIKOR Top 425 |
| `АКЗ материалы TAIKOR` | элементы только с антикоррозионной защитой | TAIKOR Primer 150, TAIKOR Top 425 |

На каждом листе:

1. **Шапка** — QR-код и логотип «ТЕХНОНИКОЛЬ · Проектный сервис».
2. **Блок цен** «Стоимость единицы материала:» — названия материалов, пустая
   цена (0 ₽) и единица; цены вписываются прямо в файле, все расчёты стоимости
   на них ссылаются.
3. **Заголовок** «СПЕЦИФИКАЦИЯ материалов <система>. Объект «…», адрес «…»».
4. **Многоуровневая шапка** (группы → подгруппы-материалы → «ТСП, мм» и
   «Расход, кг/м²»), под ней строка с номерами колонок 1…N — чтобы сверять
   формулы.
5. **Группы конструкций** («Группа элементов N» из формы; бетонная часть —
   «Бетонные конструкции»), строки элементов: №, элемент, тип профиля (марка
   проката), длина, ПТМ (δпр), требуемый предел огнестойкости, площади, ТСП и
   расход каждого материала.
6. **Расчёт по формулам**: теоретический расход = площадь × расход,
   практический = теоретический × коэффициент потерь (1.25 ОЗМ, 1.03 ОЗБ,
   1.43 TAIKOR), стоимость = практический × цена из блока цен.
7. **ИТОГО** — суммы по всем расчётным и стоимостным колонкам.

Оформление: Times New Roman 11, тонкие рамки, шапка и ИТОГО жирным, А4
альбомная, поля 0.25 дюйма, таблица вписывается в страницу по ширине.

## Две площади: огнезащита и АКЗ

Огнезащиту считают по нагреваемым сторонам, а АКЗ и финишное покрытие — по всей
поверхности конструкции. Поэтому на листе TAIKOR две колонки:

- **«Площадь покрытия огнезащиты, м²»** — по нагреваемым сторонам (`areaM2`
  элемента); по ней считаются составы TAIKOR (и Extra);
- **«Площадь покрытия АКЗ, м²»** — по полному периметру (`akzAreaM2`); по ней
  считаются грунт Primer 150 и финиш Top 425.

Движок возвращает обе площади (`areaM2` и `akzAreaM2`), а материалы
распределяются между ними так же, как в легаси-отчёте. У конструкции только с
АКЗ площадь окраски — это полная поверхность, обе величины совпадают.

## Откуда берутся числа

| Что | Источник |
|---|---|
| ТСП и расход TAIKOR | таблица `x500` по покрытию, пределу R и δпр (та же строка, из которой движок взял толщину) |
| ТСП плиты ОЗМ/ОЗБ, коэффициент | расчёт движка (`delta` элемента) и `calculation_config.json` |
| Клей, штукатурка, анкер, грунт, финиш | `materials_rt.json`: `rate` (не ниже `qMin`), `layerMm` для ТСП |
| Тип профиля | марка проката из `roll.json` по `rollId` |
| Площади | `areaM2` и `akzAreaM2` элемента из ответа расчёта |

## Отличия от легаси-файла `report.xlsx`

- QR-код и логотип вставлены одной картинкой (в легаси это две картинки, а QR
  дополнительно вёл по ссылке) — ссылку можно добавить, если нужен адрес;
- название листа TAIKOR сокращено до 31 символа (ограничение Excel):
  «TAIKOR FP Extra + TAIKOR FP Graphite» → «Taikor FP Extra + FP Graphite»;
- формулы, порядок колонок, строка номеров колонок и ИТОГО повторяют пример.

## Проверка

`backend/internal/export/xlsx_report_test.go` собирает расчёт с элементами ОЗМ,
TAIKOR (обогрев сверху — площади различаются), АКЗ и бетонной частью, проверяет
листы, блок цен, заголовок, объединения шапки, две площади, картинку шапки,
формулы с разными площадями и SUM в ИТОГО. Сохранить пример файла:

```bash
OZM_REPORT_OUT=report-sample.xlsx go test ./internal/export/ -run TestXlsxReportStructure
```
