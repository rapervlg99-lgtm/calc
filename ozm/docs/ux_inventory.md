# UX inventory — текущий/паритетный UI

## User journey

1. Meta объекта: название, адрес, согласие ПДн, степень огнестойкости здания
2. Конструкции: по умолчанию одна конструкция без группы; группы — по кнопке
   «Добавить группу конструкций», конструкция попадает в группу переносом
   (селектор «Без группы» или перетаскивание):
   - профиль (семья/форма) + ГОСТ сортамент или ручные размеры
   - тип конструкции (несущая / самонесущая)
   - R15…R240
   - стороны нагрева L/T/R/B
   - длина, количество
   - покрытие (ОЗМ / TAIKOR Epoxy / Graphite / Extra+Graphite / АКЗ)
   - метод (короб / контур)
   - для TAIKOR: primer / enamel flags
3. Опционально бетон: площадь + R180/R240
4. Рассчитать → таблица элементов (δпр, δ, V, exclusion) + BOM
5. Выгрузка Excel / PDF / Word

## Валидации

- consent = true обязателен
- objectName, address обязательны
- lengthM > 0, quantity > 0, ≥1 конструкция (групп может не быть вовсе)
- предел огнестойкости R не обязателен: у АКЗ (покрытие «АКЗ») поле скрыто, у
  огнезащитного покрытия можно выбрать «не задан» — движок сообщит об этом в
  результатах, но запрос не отклонит

## Exclusion / aside сообщения

- не задан предел огнестойкости R (ОЗМ/TAIKOR без R)
- недостижимый R при данном δпр (t500 / x500)
- АКЗ в этот список не попадает: конструкция считается без огнезащитного
  материала, с площадью окраски и без сообщений об ошибке

## Состояния

- loading dicts / error dicts / empty result / calc error / success

## Ссылка обмена расчётом

- При входе в калькулятор ссылка создаётся сразу: адрес получает токен `?n…`
  (как на calc.tn.ru), правки уходят в неё через 800 мс после изменения формы.
- Ссылку можно отправить коллеге: открывший видит тот же расчёт и может
  пересчитать или выгрузить его. Кнопка «Поделиться» копирует адрес в буфер.
- Согласие на обработку данных по чужой ссылке не восстанавливается — его
  ставит каждый пользователь сам.
- Подробности и API — `docs/share_links.md`.

## Масса 1 м при импорте распознанной спецификации

Масса подставляется из справочника масс (по марке) или из сортамента
калькулятора (по марке и ГОСТу профиля), иначе считается по размерам сечения.
Если марка не нашлась нигде, строка получает «Нужен ввод массы».

Обозначения в спецификации и в справочнике пишут по-разному, и это
нормализуется при поиске:

- значки типа профиля снимаются с обеих сторон: «L100×7» (справочник) =
  «100х7» (спецификация), «□100×100×4» = «Гн100х4», «ГН. 180-50-4» =
  «Гн[180х50х4»;
- «×», «х», «x», «*» считаются одним разделителем, дефис между цифрами —
  тоже («25-26-2» = «25×26×2», так записаны гнутые профили в справочнике);
- равнополочный уголок в спецификации пишут двумя числами («60х4»), в
  справочнике — тремя («60×60×4»); квадратная труба так же («100х4» =
  «100×100×4»).

Вид профиля определяется **по номеру ГОСТа сортамента**, а не по названию
группы: название может врать («Уголки стальные горячекатаные равнополочные», а
ГОСТ 19771-93 — это гнутые уголки), и тогда марка искалась не в той форме
сортамента и «не находилась в ГОСТе». По ГОСТу определяются уголки и швеллеры
(8509/8510 — горячекатаные, 19771/19772 — гнутые уголки, 8240/5267 — швеллеры,
8278/8281 — гнутые швеллеры); у двутавров и тавров общие ГОСТы (26020, СТО АСЧМ
20-93), поэтому там вид по-прежнему задаёт название группы.

Обломки значков и служебные префиксы в обозначении («[Н.100х5», «ТН.120х5»,
«O 80х80х4», «ТН.口180х140х5») снимаются при поиске.

Если ГОСТ профиля указан, но марки в нём нет, масса **не** подставляется из
другого стандарта: у одной марки в разных редакциях разная масса (40Б2 — 66,0
по действующей редакции и 54,7 по ГОСТ 26020-83), поэтому строка идёт на ручную
проверку. Когда масса найдена в другой редакции того же стандарта, она
подставляется, а строка помечается «Требует проверки».
