# UX inventory — текущий/паритетный UI

## User journey

1. Meta объекта: название, адрес, согласие ПДн, степень огнестойкости здания
2. Конструкции: по умолчанию одна конструкция без группы; группы — по кнопке
   «Добавить группу конструкций», конструкция попадает в группу переносом
   (селектор «Без группы» или перетаскивание):
   - профиль (семья/форма) + ГОСТ сортамент или ручные размеры
   - тип конструкции (несущая / самонесущая)
   - R15…R240
   - стороны нагрева L/T/R/B
   - длина, количество
   - покрытие (ОЗМ / TAIKOR Epoxy / Graphite / Extra+Graphite / АКЗ)
   - метод (короб / контур)
   - для TAIKOR: primer / enamel flags
3. Опционально бетон: площадь + R180/R240
4. Рассчитать → таблица элементов (δпр, δ, V, exclusion) + BOM
5. Выгрузка Excel / PDF / Word

## Валидации

- consent = true обязателен
- objectName, address обязательны
- lengthM > 0, quantity > 0, ≥1 конструкция (групп может не быть вовсе)
- предел огнестойкости R не обязателен: у АКЗ (покрытие «АКЗ») поле скрыто, у
  огнезащитного покрытия можно выбрать «не задан» — движок сообщит об этом в
  результатах, но запрос не отклонит

## Exclusion / aside сообщения

- не задан предел огнестойкости R (ОЗМ/TAIKOR без R)
- недостижимый R при данном δпр (t500 / x500)
- АКЗ в этот список не попадает: конструкция считается без огнезащитного
  материала, с площадью окраски и без сообщений об ошибке

## Состояния

- loading dicts / error dicts / empty result / calc error / success
